Proyecto de aprendizaje de C y emulación que consiste de un emulador de Chip 8. En este proyecto estoy siguiendo [un tutorial de YouTube del usuario @QuesoFuego](https://www.youtube.com/playlist?list=PLT7NbkyNWaqbyBMzdySdqjnfUFxt8rnU_) en la plataforma.


Con este proyecto pretendo conseguir varios objetivos:

- Conocimientos básicos de C, tanto sintaxis como conceptos clave como la administación de memoria o punteros.
- Entendimiento base de como funciona un emulador y como programar cada parte a partir de documentación del hardware/software.
